Encabezado propio del iframe

Desplázate dentro de este iframe para llegar a los elementos objetivo. Este texto existe solo para crear scroll interno propio, que es lo que permite comprobar que el overlay del highlight se reposiciona cuando el scroll ocurre dentro de un documento embebido y no en la página anfitriona.

Los eventos de scroll no cruzan las fronteras entre documentos, así que un handler suscrito únicamente a la ventana superior no se enteraría de este desplazamiento. Por eso content.js se suscribe también a las ventanas de los iframes contenedores.

Si el overlay se queda anclado en su posición original mientras este contenido se mueve, la suscripción al scroll del iframe está rota. Si acompaña al elemento, funciona.

Relleno adicional para asegurar que el recorrido de scroll sea claramente observable y que los dos elementos objetivo empiecen fuera de la vista.
